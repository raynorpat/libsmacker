# build_smk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a production SMK2 encoder tool from image directories/WAV or smk2avi-style AVI input.

**Architecture:** Thin CLI over a reusable, callback-fed encoder. Three deterministic passes: histogram -> palette/symbol counting -> encoding. Canonical Smacker Huffman trees, delta block video, raw PCM audio, atomic writes, libsmacker round-trip verification.

**Tech Stack:** C99, libc, CMake 3.16+, CTest, existing libsmacker library (verification only).

**Spec:** `docs/superpowers/specs/2026-11-08-build-smk-design.md`

## Global Constraints

- C99, libc only, `-Wall -Wextra`, CMake 3.16+.
- SMK2 only, 256 colors, 6-bit palette components via `palmap`, LSB-first bitstreams.
- Frame chunks padded to a multiple of 4; low size bits are flags.
- Deterministic output; no timestamps.
- Exit codes: 0 success, 1 usage, 2 input, 3 encode, 4 verify.
- Warnings/errors on stderr; stdout silent unless `--verbose`.
- Tools built with `SMACKER_BUILD_TOOLS=ON`; tests with `SMACKER_BUILD_TESTS=ON`.

## Review Focus

1. Truncated/corrupt TGA/BMP/PCX/WAV/AVI: clean error, no crash or OOM.
2. Non-multiple-of-4 dimensions: pad or `--strict` error, no out-of-bounds.
3. Empty directory, single image, no audio: clean error or valid file.
4. Audio shorter/longer than video: silence pad or truncate warning, sample-accurate.
5. Adaptive palette switching and 6-bit palette round-trip.
6. Huge frame counts and size-field overflow.
7. AVI odd widths (stride) and multi-track mapping.
8. 24-bit audio warning and 16-bit reduction.

## File Structure

```
src/encoder/
  smk_encoder.h   API: options, source callbacks, smk_enc_encode()
  encoder.c       three-pass orchestration
  bitio.c/h       LSB-first bit writer and test reader
  huffman.c/h     canonical tree build + packed serialization
  quantize.c/h    histogram, median cut, k-means, LUT, dither
  video.c/h       block classifier, runs, frame bitstream
  container.c/h   palette/audio chunks, header/tables, atomic writer
  verify.c/h      libsmacker round-trip comparison
  image.c/h       TGA/BMP/PCX -> RGB24
  wav.c/h         WAV -> PCM, 24-bit reduction
  avi.c/h         smk2avi-style AVI -> RGB + PCM tracks
src/tools/build_smk/
  main.c          CLI only
  image_dir.c/h   directory scan, natural sort, padding, source adapter
tests/
  test.h test_main.c test_util.c/h
  test_bitio.c test_huffman.c test_quantize.c test_video.c
  test_image_tga.c test_image_bmp.c test_image_pcx.c test_wav.c
  test_image_dir.c test_avi.c
  test_roundtrip_still.c test_roundtrip_audio.c test_roundtrip_delta.c
  test_roundtrip_palette.c test_verify.c test_roundtrip_avi.c
```

`SMACKER_ENCODER_SOURCES` and `SMACKER_TOOL_INPUT_SOURCES` are CMake variables used
by both `build_smk` and `smk_tests`.
